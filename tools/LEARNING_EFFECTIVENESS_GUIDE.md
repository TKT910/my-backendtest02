# 📊 学習効果分析システムの使用ガイド

## 概要

このシステムは、ログデータから以下の4つの観点で**学習効果を深層分析**します：

| Q | 分析観点 | 測定対象 | 仮説 |
|----|---------|--------|------|
| **Q1&Q3** | 🤖 AIの「問い」の有効性 | プロンプトテンプレート選好 | 特定のテンプレートを受け取ったユーザーが高い「気づき」を得たか |
| **Q2** | 💭 内省のプロセス | 試行錯誤の回数 | 回答→修正で試行錯誤が多いユーザーは高い「深い内省」を実現しているか |
| **Q4** | 👁️ 視覚的フィードバック | 修正直後の確認行動 | テキスト修正直後に「元文との比較」を確認するユーザーは「洗練された実感」を得ているか |
| **Q5** | 🎯 自律化への予兆 | 過去参照→編集の連鎖 | 過去の反省を参考にして編集するユーザーは「自律化」へ向かっているか |

---

## 🚀 使い方

### ステップ1: ログの収集と拡張

```bash
# ユーザーがツールを使用してログが記録されたら、
# 既存ログを分析用形式に拡張します
python3 tools/convert_logs_for_analysis.py
```

**処理内容：**
- 全ログファイルを読み込み
- AI生成ログからプロンプトテンプレートタイプを推定
- 時系列で関連ログをマッピング
- 拡張フィールドを追加

**出力：**
```
data/logs_enriched.jsonl
├─ 元フィールド: timestamp, user_id, step, ...
├─ 新フィールド: trigger_template_ids, time_since_last_answer_seconds, ...
└─ マッピング: reviewed_history_before_answer, followed_by_comparison_check, ...
```

### ステップ2: 学習効果分析

```bash
# 拡張ログから各観点の分析を実行
python3 tools/analyze_learning_effectiveness.py
```

**出力ファイル:**
```
results/学習効果_深層分析.xlsx
├─ Q1Q3_テンプレート効果: AIテンプレートと気づきスコアの相関
├─ Q2_試行錯誤: 回答→修正ステップの試行度
├─ Q4_視覚フィードバック: 修正直後の確認パターン
└─ Q5_自律化予兆: 過去参照→編集のシーケンス
```

## 📋 拡張ログのスキーマ

### 基本情報（すべてのログに含まれる）

```json
{
  "timestamp": "2026-02-09T10:17:32.096Z",
  "user_id": "AAA23179",
  "step": "🤖_ai_feedback_received",
  ...
}
```

### AI反応ログ（📝_ai_feedback_received）に追加される情報

```json
{
  "trigger_template_ids": ["A1", "B2", "A4"],  // ← テンプレートタイプ推定
  "template_distribution": {
    "concrete_count": 2,   // A系（具体化）の数
    "abstract_count": 1    // B系（抽象化）の数
  }
}
```

**テンプレートID一覧：**
- **A系（具体化）:** A1（定量基準）, A2（比較対象）, A3（影響度）, A4（評価基準）, A5（未来行動）, A6（プロセス）, A7（根拠）, A8（用語定義）, A9（論理の飛躍）
- **B系（抽象化）:** B1（共通パターン）, B2（分類軸）, B3（テーマ統合）, B4（思考経路）, B5（視点転換）

### 反省保存ログ（📝_reflection_saved）に追加される情報

```json
{
  "question_id": "q0",           // ← どの質問への回答か
  "answer_length": 127,           // ← 回答文字数
  "reviewed_history_before_answer": true,  // ← 事前に過去参照したか
  "time_to_next_edit_seconds": 180  // ← この回答後、修正までの秒数
}
```

### テキスト編集ログ（✏️_text_edited）に追加される情報

```json
{
  "time_since_last_answer_seconds": 120,  // ← 最後の回答からこまでの秒数
  "related_question_id": "q0",            // ← 関連する質問ID
  "followed_by_comparison_check": true    // ← 修正直後に比較確認したか
}
```

### 元文表示切替ログ（👁️_original_text_toggled）に追加される情報

```json
{
  "time_since_last_edit_seconds": 3,    // ← 直前の修正からの秒数
  "viewing_context": "after_edit"       // ← "after_edit" or "delayed"
}
```

### 反省履歴閲覧ログ（💭_reflection_history_opened）に追加される情報

```json
{
  "context_before_edit": true   // ← マーキング用（分析スクリプトで使用）
}
```

## 📊 分析結果の読み方

### Q1&Q3 分析: テンプレート効果

```
📊 Q1&Q3 分析: AIテンプレートの有効性
└─ 平均AI反応数: 3.5回
└─ 具体化テンプレート(A系)の平均: 2.1回
└─ 抽象化テンプレート(B系)の平均: 1.4回

📈 テンプレートタイプの利用頻度:
  A1: 8回 (18.6%)  ← 「定量基準」が最も多く出現
  B2: 6回 (14.0%)
  ...
```

**読み方:**
- 多く出現したテンプレから、ユーザーがどの種類の「曖昧さ」に陥りやすいかが分かる
- 後でGoogle Forms回答と照合：「A1が多い学習者は、Q1スコアが高いか？」を検証

### Q2 分析: 試行錯誤

```
💭 内省プロセスの統計:
└─ 1回答あたりの平均試行回数: 2.3回  ← 回答してから修正した平均回数

🔄 高試行グループ（中央値以上）: 3人
   平均試行回数: 3.1回
   → これらのユーザーが Q2（深い内省）で高スコアを得たか確認
```

**仮説検証:**
- 「試行錯誤が多い → 深い内省」という相関があるはず

### Q4 分析: 視覚的フィードバック

```
👁️ 視覚的フィードバック確認パターン:
└─ 修正直後（5秒以内）の確認率: 45.2%
└─ フィードバックパターンあり: 5人 / 8人

✅ フィードバック確認ユーザー (5人):
   平均即座確認回数: 2.3回
   → Q4スコア（洗練された実感）が高いはず

❌ フィードバック確認なしユーザー (3人):
   → Q4スコアが低いはず
```

**仮説検証:**
- 「修正後に比較 → 洗練感を実感」という行動が見える

### Q5 分析: 自律化の予兆

```
🎯 自律的学習パターン:
└─ 自律パターンありユーザー: 4人 / 8人
   (過去参照 → 10分以内に編集)

✅ 自律パターンありユーザー (4人):
   平均参照→編集率: 78.5%
   → Q5（自律化）スコアが高いはず

❌ 自律パターンなしユーザー (4人):
   → ユーザーはまだ「過去から学ぶ」プロセスが定着していない
```

**仮説検証:**
- 「過去参照の習慣 → 自律的学習態度」という発展段階が見える

## 📝 トラブルシューティング

### Q: 「AI反応ログがありません」と出た場合

→ 既存ログには新しいstep名（`🤖_ai_feedback_received`）がまだ含まれていません。  
→ 新規ユーザーのログからは記録されます。

### Q: 「反省ログがありません」と出た場合

→ ユーザーが反省機能（💭 気づきを記述）をまだ使用していません。  
→ 実際の利用で記録されれば分析可能になります。

### Q: テンプレート推定が「すべてA1」のように偏っている場合

→ キーワードマッチングが不正確な可能性あります。  
→ APIレスポンスを直接確認して微調整してください。
